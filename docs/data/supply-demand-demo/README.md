# 统一企业星链图演示

入口：园区服务 → 企业星链图 → 体验演示。仅一个演示入口。

始终使用北控宏创公开资料中的17家企业，保持相同企业ID、名称、主营行业和公开资料。右上角连接方式切换“同行业 / 供需匹配”，不切换企业数据集。原8家虚拟公司已从运行时移除。

## 数据与事实边界

- 原始公开事实：`packages/desktop/src/renderer/starMap/beikongDemo.json`，由北控宏创CSV生成，本轮未修改。
- 模拟供需扩展：`packages/desktop/src/renderer/starMap/supplyDemo.ts`。
- 模拟字段单独保存为`demoProductsServices`和`demoCooperationNeeds`，不覆盖公开产品、能力或合作需求。
- 页面及企业详情明确标注供需为模拟，不代表该公司真实业务或采购意向。
- 只有demo来源参与模拟字段匹配；真实接口即使意外携带同名字段，也只使用原公开资料字段。
- 需求完成/恢复仅修改组件会话状态，不写数据库、不创建真实账号或订单；退出并重新进入演示恢复初始状态。

## 可复现操作

1. 进入演示：17家企业，同行业11对关系。
2. 切换供需匹配：仍为17家企业，25对企业关系；具体方向及条目在详情区展示。
3. 国金源富关联7家，杰创永恒关联1家，特智诚没有匹配，节点大小随关联数变化。
4. 点击盈科视控，可查看模拟供给“工业视觉检测”及需求“自动化设备、生产管理软件”。
5. 完成“自动化设备”需求后，该方向消失；金钢科技仍模拟需要工业视觉检测，因此双方连线保留。
6. 完成“生产管理软件”需求后，与国金源富的连线消失；恢复后连线及度数恢复。
7. 切回同行业，企业名单和公开资料不变，连线按行业重新计算。

## 规则

NFKC标准化、去首尾空格、忽略大小写、去一个常见供需前缀和尾部标点后精确匹配；不靠行业、包含词或AI语义推断。自环排除，多条需求及两个方向仅计一个关联企业。真实合作需求仍在企业资料表单维护，完成后移除并保存。

初始化先后台预热布局，按真实容器尺寸瞬时适配，再显示画布；不会在展示后自动缩放。已有会话相机直接恢复，手动适配仍可用。
