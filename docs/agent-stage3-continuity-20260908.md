# 阶段 3：安全点纠偏与版本化连续性

日期：2026-09-08。仅本地源码与离线回归，不包含推送、上线、应用重启或真实付费模型评测。

## 实现

1. **同一份权威记录**：`TaskContinuityLedger` 登记本机用户原始任务及 append / replace / pause 事件，分别记录已接收版本和已应用版本。任务图、约束文件基线、原生证据检查点与工具回执放在原有恢复记录内，原子写入并 flush。没有增加第二个 Agent Loop、调度服务或数据库。
2. **运行中调整入口**：新版桌面在运行时允许发送纯文本，选择“补充当前任务 / 替换当前任务 / 安全点暂停”。通道绕过普通企业办事分派，不能误把纠偏当作新的企业数据操作。旧客户端没有协商 steering v1 时维持原排队行为。带附件的追加任务仍不进入此通道。
3. **接收不冒充应用**：接收时同步设置调度栅栏，先持久化再确认接收；当前模型或工具结束后才应用。未启动的旧调用取消；迟到的工具批准不能复活旧操作；异步产物检查期间也不能提交旧版最终回答。进行中的外部操作不被假装撤销，先收集回执；结果不明则进入核对。
4. **版本与授权边界**：核对会话归属、本机来源、turn ID、expectedRevision 和 clientMessageId。同 ID 同内容重复投递幂等，不同内容或过时版本拒绝。替换正向目标不自动解除原有禁止、保持、范围与人工判断项；解除限制须用原生协议明确列出已有约束 ID，普通自然语言、模型输出和旧批准都不等于解除。桌面当前不提供“解除限制”快捷按钮。
5. **任务图投影**：新版本重建当前图；保留仍能引用当前需求的 objective 定义及本机观察。旧图进入同一记录的历史，未完成节点标记取消；旧的失败分支不能继续调度。图/证据检查点带请求版本，不能混用其他版本。
6. **恢复与证据**：初始化只恢复状态，不自动启动模型。本机明确继续时读取完整版本化记录，不依赖最近 200 条消息或压缩摘要猜任务。保留原先“保持不变”的文件指纹，不用重启时的文件内容覆盖基线。已绑定测试保留命令回执、具名用例与输入文件指纹；输入变化、证据缺失或超限则不通过，需要重新验证。产物回执恢复后同样重新比对实际文件版本。只读原文、无输入文件绑定的旧过程验证、人工批准不自动成为有效的新证据。
7. **不重复副作用**：同工具、同参数指纹且已确认成功的发送/部署等调用只返回旧回执。未取得终态的外部操作及本机写入保守进入核对；不同任务、工作目录或来源不能悄悄接管恢复记录。复用旧回执不能被当成新的策略修复成功。
8. **压缩**：控制元数据不再重复首轮原始输入；调整、恢复或检测到当前用户任务从模型上下文丢失时，补入最新权威请求和任务图。摘要只是上下文材料，无权修改原生任务版本。已有结果保留在消息与回执中，未通过当前验收的工作不会因此宣告完成。

## 明确边界

- 安全点是当前模型调用或工具批次结束、下一条原生调用之前；不会强行回滚已经对外生效的发送/部署，也不承诺瞬间中断不响应取消的工具。
- 确定取消旧批次，不等于能独立理解所有新目标的语义。含糊操作范围由阶段 1 原生约束保守拒绝；语义遗漏、弱测试和任务语义审查仍是阶段 5。
- 防重放按工具名和完整参数指纹识别；不能证明“改了参数仍是同一业务请求”。跨服务全局 exactly-once 仍需服务端幂等键/业务回执支持。结果不明先核对，不能用“继续”替代核对。
- 本机恢复文件是受限用户数据，不是对恶意本机同权限代码的防篡改沙箱；未新增 OS 凭据保险库、跨进程事务数据库或跨机器迁移协议。模型输出和普通任务计划工具不能直接提交原生证据检查点。
- 每任务最多 128 次调整，任务正文最多 32000 字符、单次调整 16000 字符；恢复记录最多 16 MiB。达到上限明确停止，不裁掉硬约束继续执行。原生检查点最多 256 条绑定观察、128 个产物；不能完整保留的验证需重做，不冒认通过。
- 证据新鲜度只覆盖已观察/声明的输入，并非完整依赖图；阶段 2 的文件格式、容量、视觉质量及未独立沙箱解析等限制继续适用。
- 未运行真实模型前后对比、实际 GUI 操作或安装包重启；没有一次完成率、成本降低或竞品评分。不能把本阶段测试通过当作生产发布批准。

## 回滚

使用阶段 2 冻结快照对照本阶段涉及文件逐项回退，不要 reset 整个脏工作树，也不要覆盖其他招聘、记忆与 Skill 改动。客户端没有 steering 能力协商时自然退回旧排队。若降级版本不能识别阶段 3 的活动恢复记录，应先保留备份并核对/结束该任务，不能让旧版本静默重放。
