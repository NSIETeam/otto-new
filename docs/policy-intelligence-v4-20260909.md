# 政策智能服务：来源、附件、批次与消息闭环

本次为本地源码实现，本任务未执行推送、部署、生产企业接口或付费模型调用。共享工作区另有提交操作，不将其他任务的提交或发布状态作为本次验证结果。不是“全国政策已全部收录”或“所有附件都可自动解读”的声明。

后续发布记录（2026-09-09）：用户已授权将本次政策源码、测试及本文与198个Agent候选文件公开推送到 `NSIETeam/otto-new`。这是源码同步，不是安装包发布或服务器部署；上文记录的是实现阶段的操作边界。

## 1. 全国来源接入

- 保留原有8个国家、城市和区县来源，新增中国内地31个省级政府入口，共39个来源。直辖市按市级范围匹配，省级资料无需虚构城市。
- 域名依据北京市政府公开省级政府导航核验：<https://www.beijing.gov.cn/images/public_foot_response_2020.js>。只使用HTTPS、精确域名白名单；不执行网页JavaScript，不降级TLS，不追随不受控重定向。
- 门户适配器从已审核主站发现有限政策栏目，识别多种“文件/法规文件/最新文件/政策文件库”导航。最多3个栏目、6个初始条目；原有直连来源最多12个初始条目。
- 服务端逐来源限时30秒，并按上次尝试时间轮换，避免前几个慢站一直占满采集预算。先收录公共正文，再做有额度限制的模型解读；不让模型调用阻塞后续地区。
- 页面“全国官方来源接入情况”展示最近检查、条目数，以及未核验、成功、部分失败、不可用状态。采集到条目不等于当地政策全量覆盖，也不等于资格诊断已经完成。
- 原有历史重查之外，增加最多4个、仅一层的原文关联补采。不进行无限爬站。

## 2. 附件与原文依据

- PDF：使用已有PDF解析依赖，在受限worker中提取文字和逐页定位。禁用PDF脚本/eval、自动外部加载；60页、8秒、内存和文本大小限制。不打开WPS或其他阅读器。worker资源限制不是操作系统沙箱承诺。
- DOCX：正文、表格段落、页眉页脚、脚注尾注文字，保留XML部件及段落位置。
- XLSX：工作表共享字符串、内联文字、数值及单元格位置；不执行公式或外部连接。公式、图片和嵌入内容触发人工核验。
- ZIP：有数量和深度限制的附件组合，复用既有ZIP边界/CRC/解压膨胀检查；不落地解压，不执行内容。
- 每份附件记录SHA-256和解析状态。完整提取的依据进入同一政策正文，沿用页面及对话的引用核验、材料和资格判断链路；未完整解析的附件继续阻止确定性资格判断。
- 不支持的DOC/XLS、RAR/7z、扫描件、图表/公式等不冒充已解析。超限、畸形XML、DTD/外部实体、损坏ZIP、HTML伪装PDF等拒绝。
- 不在白名单的附件保留“缺失依据”标记，禁止自动访问，不能因链接被过滤而误判为无附件。临时附件失败不得发出确定性的截止提醒。
- 识别常见政府正文容器，避免侧栏新闻变化触发虚假政策修订；附件取自正文及独立附件容器，不把网站客户端、打印/PDF下载控件当作必需附件。原文里的未批准附件仍保留缺失标记。

## 3. 历年与批次关系

- 从标题提取不歧义年度及“第几批”标记。
- 仅通过原文直接引用，或两份原文共同引用同一办法，建立可追溯关系；显示关联依据链接。
- 同名、相似标题不是关系证据；不同地区不混合。关联不代表替代、继承或条件相同。
- 旧年度条件、材料、期限不自动复制到新批次；点击关联项会清理筛选条件并定位对应政策。
- 原文版本快照额外保留附件摘要与引用关系。没有被采集/没有明确引用的历史文件不会被凭空关联。

## 4. “我的消息”闭环

1. 企业服务已启用时，成员或管理员点击“关注截止与变更”；也可在政策对话列表之后说“关注第1项政策”。不自动订阅所有政策。
2. 服务端对已关注、所在地匹配、账号仍有效的政策生成提醒。包括最后7/3/1天、已截止和原文修订；日期按北京时间处理。离线后回到App仍可读取已经保存的提醒。
3. 通知进入普通会话列表中的“政策助手”，与私信、跨企业联系人和园区客服消息按时间混排，不增加单独的园区客服栏目。
4. 点击会话确认已读；导航角标同步；读过、退出、再次进入仍可回看，已读接口只能操作本账号本企业已有消息。
5. 消息可返回对应政策与材料，或由用户主动打开官方原文。不会自动提交申报。
6. 取消关注只停止未来提醒，保留历史。重复调度、重复采集、进程重建不重复创建相同事件；同一原文修订后续解读补全不会新建第二条未读消息。

使用既有加密PolicyStore，无数据库表迁移；邮箱键同时绑定企业和账号。每账号最多关注100项。提醒不调用模型，无订阅时不扫描政策正文；无变化时不重写邮箱。网络采集关闭不影响已缓存政策的免费期限提醒，企业关闭服务则停止该企业的新提醒。

新增API：`GET /enterprise/policy-intelligence/inbox`、`POST /enterprise/policy-intelligence/inbox/read`；身份由服务端会话决定。新增能力声明 `policy_intelligence_inbox_v1`，SQLite版和集群版同时声明。新客户端对旧服务器先提示升级，不直接请求不存在的提醒接口。IPC及客户端固定请求账号/服务器，切换账号后丢弃旧响应，避免跨账号误标已读。
