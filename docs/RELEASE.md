# Otto 历史桌面发布记录（禁止用于当前发布）

Otto 1.9.14 的受支持自动部署目标是 `enterprise-oneclick` 单机企业服务。集群
PostgreSQL 配置需走独立的迁移、能力兼容和容灾验收流程；本发布流程不会把它声明为
1.9.14 稳定生产配置。

> 本页原流程形成于 v1.4.x–v1.5.x，已失效。它曾包含手工创建 Release、覆盖资产和
> 未签名分发等做法，不满足当前的双仓兼容、供应链签名、企业服务器部署、事务回滚和
> 公网验收要求。为避免事故，旧命令已从文档中移除。

当前发布只能按以下两份权威文档执行：

- [发布前检查](./release-preflight.md)：人工与自动硬门禁、签名和外部前置条件。
- [GitHub Actions 发布契约](../.github/workflows/README.md)：SHA-256 绑定的双仓发布前
  创建意图与 `latest` 快照、可幂等清理的草稿、企业部署、正式仓优先/兼容仓最后公开、更新镜像及精确恢复此前
  `latest` 的唯一受支持流程。已公开 Release 不得退回草稿，版本号不得复用。

不得直接运行 `gh release create` / `gh release upload`，不得覆盖同版本资产，也不得用
本地构建产物替换工作流锁定的签名 artifact。历史版本的经验记录只能从 Git 历史查看，
不能作为运维指令。
