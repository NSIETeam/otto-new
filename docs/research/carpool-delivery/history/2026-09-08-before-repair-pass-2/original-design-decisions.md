# 拼车实现设计与决策（部分交付）

## 范围与状态

本批实际实现为既有发布/个人匹配基础的纠错与可靠性增强，不能认定 PRD 阶段一完成；阶段二和阶段三尚未实现。未增加假页面、模拟生产接口或无法执行的邀请/群聊按钮。没有推送、部署、发布安装包。

## 已落地模型与事务

- SQLite `park_carpool_intents.version`：现有表通过 PRAGMA table_info 检测后增加，默认 1。保存时比较规划前版本，停止时递增版本。已有数据库迁移不删除记录。
- SQLite `park_carpool_publications`：账号+请求键主键、版本、加密请求记录。使用既有字段加密与账号/请求键 AAD。保存意向及成功回执在同一个 SAVEPOINT 中同步完成，回执失败整笔回滚。
- PostgreSQL 保留 `enterprise_business_records` 的 `carpool_intent`，增加 `carpool_publication` 类型。`saveCarpoolIntentAtomically` 在同一事务保存意向和加密回执；现有意向 SELECT FOR UPDATE，比较规划前版本。创建竞争由唯一约束拒绝，不再读取竞争结果后覆盖。
- Publication 状态：未存在 → 30 秒租约 pending → 原子完成 receipt；失败释放租约；进程中断后租约到期可重试。相同键不同内容拒绝；成功回执不会被后来修改覆盖。租约使用服务端墙上时钟，需正常时间同步。
- 请求回执仍包含加密位置副本；其保留/清理任务尚未实现，必须纳入后续清理设计。不得把它当作已通过位置保留门禁。
- 页面与对话发送 `requestKey` 和 `expectedVersion`。表单基准版本独立于结果刷新；对话草稿保存原版本。旧客户端仍可不传新字段，兼容路径不提供客户端旧表单保护，不能把旧客户端当完整验收客户端。

## 路线与隐私决策

- 用有向线段投影区间、40 米邻近带裁剪及区间合并替代中点判定。方向差上限 15 度。共同里程取两方向覆盖量及较短路线长度的最小值，向下取整；百分比按 2C/(L1+L2)。
- 40 米、15 度为本次几何近似工程参数，并非客户批准的道路匹配阈值。无法辨别相邻道路、立交和不同高度，不编造道路名称。解释明确说明几何近似。
- 移除最多 128 点等间隔抽样；改为 0.5 米平面偏差的形状简化，强制保留局部方向反转点并去掉连续重复点。Provider 输入最多 20,000 点，简化后最多 2,048 点；超限明确拒绝，不静默增加误差。短绕行、同一直线折返都有先红后绿回归。上述限制为工程假设，仍不宣称真实路网准确率已验收。
- 候选不再从任意私人标签删数字后输出区域，而是安全隐藏具体位置。结构化行政区/公共 POI 区域模型及路线脱敏预览仍未完成，因此该安全兜底不等同于完整区域展示交付。
- 原有地图 Provider、服务端密钥、超时、CSP 与企业私聊隔离边界保持。页面/对话去除北京搜索参数，用户可用地名限定城市；尚未新增园区城市配置入口。

## 日期、状态与输入

- 按北京时间检查 travelDate、departureTime 与当前发布日一致；拒绝无时区出发时间和无效日历日期。
- 规划前读取版本，规划后复核身份、企业、园区、时间与当前状态，再执行数据库 CAS。
- 重复停止返回停止后的真实记录。“仍在寻找”是独立 POST 动作，刷新不更新确认时间；该动作不能重新启动停止/过期意向。
- 状态读取仍主要采用有效期派生；后台过期通知、陈旧暂停、位置删除与身份变更任务未完成。
- 两数据库按 ID 分页召回后统一业务筛选；解密失败与畸形候选分别隔离并返回失败数量。尚无持久失败重试队列、全园区计算预算和增量索引。

## API 与入口

保留 GET /enterprise/park-carpool、GET /matches、GET /places、PUT /intents、POST /intents/stop；新增 POST /intents/confirm，body 为 intentId。

`parkCarpoolHttp.ts` 提供真实 HTTP 业务处理，SQLite enterprise 路由适配它；PostgreSQL 路由复用同一 service 和独立 store。新增 confirm 已接通 EnterpriseClient、Main IPC、typed preload 和 ParkCarpoolDialog。

现有 `park_carpool_v1` 能力标识未改变。它目前仍只对应基础能力，不能据此声称首发完整。未公布 pairs/groups 新标识，也未通过关闭新标识把缺失功能算完成。上线前必须解决能力语义与完整功能门禁。

## 对话与页面

- 明确时间字段须有“点/时/冒号”，下午等时段转换为 24 小时；“前后20分钟”只修改浮动。
- 多地点候选要求“出发地1，目的地2”显式选择；不再静默取首项。
- 对话收集/确认/选点可取消；失败保留草稿；同会话处理锁防重复确认。修改既有意向时继承未修改字段并绑定版本。
- 拼车草稿纳入既有加密 vault 快照、恢复及草稿计数，限制账号/企业 scope 和 30 分钟有效期。未做实际进程崩溃/真机重启验收。
- 页面发布成功即保留真实回执，刷新失败单独提示，不误报发布失败。停止也直接消费回执。
- 增加筛选、人数、真实日期/停止/过期状态、未保存关闭提醒、主动确认和新候选计数提示。浏览器/真机键盘、焦点与整条消息路径尚未实测。
