2. **搜索**：加密业务载荷不进入明文全文索引。园区随机独立密钥经既有字段密钥保护，单字/双字 HMAC posting 只做候选筛选，最终解密严格复核原有子串语义。索引会暴露重复词频和候选关联，不能称作零泄漏。缺失索引返回可重试依赖状态；worker 每批100条回填，文档版本持久化保证重启续作。轮换在维护事务中清索引并生成新密钥，不提供无鉴权公开接口。稀疏候选最多200条主键查询，热门词使用排序索引；实时身份检查在每次请求执行。
3. **事务/迁移**：SQLite BEGIN IMMEDIATE 与 PostgreSQL 事务/唯一约束沿用既有仓库；业务、引用、消息绑定及 outbox 原子提交。追加迁移25–29分别为搜索扫描、维护游标、聊天附件、持久上传意图、清理扫描索引，不重写旧迁移。
4. **附件**：首次咨询/接受前消息禁止附件；接受后至多6个、每个10MB。客户端使用既有 EnterpriseE2eeCrypto 文件加密；native MLS 将含附件密钥的既有信封封装在原生 MLS 应用载荷内，不降级。服务只存密文、尺寸/摘要和授权元数据；当前批准设备签名绑定会话、消息、对象和字节摘要。上传对象在消息事务绑定前不可下载，重试复用id/密文；服务上传意图先于文件写入持久化，24小时清理中断孤儿，每批100。共享S3孤儿扫描检查市场图片及聊天引用；真实S3部署未验收。
5. **客户端恢复/文件**：pending 消息通过现有 OS 安全存储加密，密文附件目录0700、文件0600；重试保留相同请求。成功、确定拒绝、准备失败清理暂存文件；下次发送清扫24小时前未被 pending 引用的普通文件（每批100，不跟随符号链接）。新批准设备不能获得旧历史密钥，恢复建立新代际；旧历史不可解密有明确提示，撤销设备无上传/下载/发送权限。
6. **Readiness**：协议标识与园区运营开关分离。正常单机/集群组合根使用诊断探针：数据库、字段密钥、对象读写删除、图片 worker、维护任务。仅非生产、显式开关、指定前缀目录和标记文件可启用隔离本地测试；PostgreSQL还校验 Unix socket 和已标记数据目录。生产 release policy 不绕过。worker 重复启动只注册一次，停止回调只影响所属实例，注册失败不冒充就绪。
7. **清理与治理**：商品任务每批最多250条（到期优先100+轮转150），图片100，报告/申诉各100，outbox250，游标持久化。举报只冻结参与者所选证据，不赋予管理员浏览完整私聊的权限。结案证据180天，草稿30天及失联对象7天等沿用PRD；法律保全、聊天/最小记录/备份最终策略未获确认，不默认永久保留或擅自删除。双库事务屏障验证续期/到期、撤权/咨询、租约/清理与举报冻结/删除；发布引用与双worker另有回归。
8. **证据界限**：双库×两种真实加密为服务适配器测试；正常启动+真实登录HTTP另有SQLite信封流程，不能称作四组合HTTP测试。100独立会话负载采用注入传输，仅证明数据库调度。40组搜索压力为服务查询，非网络首屏。native CLI、真实加密对象和数据库均实际执行；用户取消后不运行 App、操作系统 UI 或安装包验收。
