# 供需匹配虚拟演示

独立于北控宏创公开资料数据集；全部企业名带“虚拟”标识，身份以`synthetic:`开头。
本数据不会创建真实企业、账号、采购需求或数据库记录。

数据源：`packages/desktop/src/renderer/starMap/supplyDemo.ts`。
入口：园区服务 → 企业星链图 → 供需虚拟演示。

## 演示步骤

1. 进入后自动使用供需匹配；8家虚拟企业、12对企业关系（方向与具体条目在详情中区分）。
2. 云桥软件关联6家、澄光设计关联1家、绿境园艺关联0家，观察圆点大小。
3. 点击精工制造，查看“谁能满足我的需求”和“谁可能需要我”。
4. 标记工业检测设备需求完成：该方向消失，但明眸检测仍需要精工制造的加工服务，双方连线保留。
5. 完成精工制造的生产管理软件需求：与云桥软件之间没有剩余匹配，连线消失，双方关联度同步下降。
6. 恢复需求可以恢复关系；重新进入虚拟演示重置全部需求。状态只在本组件会话内保存。
7. 切换同行业，仅明眸检测与智造装备同行；与供需关系作比较。

## 匹配和大小

- 使用已经授权返回的公开企业资料；只将产品与服务对接合作需求，不把行业标签或笼统能力当供给证据。
- NFKC标准化、去首尾空格、忽略大小写、去除一个常见前缀（如采购、寻找、提供）和尾部标点后精确匹配。不做包含词、同义词或AI语义推断。
- 同一家企业不匹配自身。同一对企业多条需求及两个方向只计算一个关联企业；详情保留方向及证据。
- 真实数据将企业当前公开填写的合作需求视作待对接条目。完成后在既有企业资料表单中移除并保存；本次未增加独立采购订单或需求工作流。
- 默认节点大小按当前模式下完整授权范围的不同关联企业数计算，大小有上限；用户已明确保存的统一大小偏好继续保留。
- 箭头从供给企业指向需求企业，不表示已经合作。超过600对的密集供需图默认收起连线，聚焦后显示直接关联；物理布局只使用连接森林，最多n-1条约束。

所有演示来源、匹配结果和统计不写入真实企业资料；不修改现有资料保存接口或其他园区模块。
