# Stage 6 — 自然输出与性能（2026-09-08）

范围：本地实现与离线回归；不推送、不部署、不调用付费模型。延续阶段 0–5 的同一运行时、约束、证据和完成门控，没有新增评审模型或第二套执行器。

## 实际改动

1. `turnControlPolicy.ts` 不再向模型发送 `final_sections`，不强制“结果 / 变更 / 验证 / 限制”等报告栏目。旧协议的 `finalSections` 只保留兼容性的 `result` 内容提示，不再表示标题要求。用户明确要求的简短 / 详细表达影响展示详略，不改变风险、预算、授权、验收标准。没有用后处理改写已审查正文，阶段 5 的正文哈希绑定仍有效。
2. 普通、无约束、未使用工具且未建立合同的回答，不注入文件/测试指令和任务合同说明。原生账本与完成检查仍然存在。遇到约束、实际工具调用、合同更新或纠偏后会恢复必要说明。正常回答不为润色增加规划/审查轮；有工具能力的会话仍等待完整模型轮次，防止文本先到、工具调用后到造成提前宣告成功。
3. `ChatView.tsx` 保留同轮旧格式正文、已有嵌套进展及最终回答之后的有价值补充。不按语义相似度删除文字：只去重完全相同的正文/段落和极少数完整、固定的空泛应答；代码块、列表、证据链接和限定条件不拆碎。原始存储不变；投影再次投影不会丢信息。用户消息、会话、轮次边界不合并。
4. 选择同轮序号最新的状态快照；终态覆盖历史片段残留的“正在思考/执行工具”标志，防止完成后仍一直忙碌或隐藏复制按钮。最终正文在先前说明之前展示，先前说明仍可展开；只有最终答复有复制/重试动作。
5. `Message.tsx` 隐藏成功的内部计划、证据审查和修复规划工具卡，但保留错误、取消和等待确认的可追溯结果。内部路由/复杂度状态继续不展示；并未移除用户需要的许可交互、未完成说明或验证记录。
6. 产物去重使用 `Prose.tsx` 的同一 Markdown 解析器判断实际文件链接，而不是 `includes(path)`。普通正文路径和代码块里的路径不会吞掉可点击的产物卡；待验证产物不因正文含链接而隐藏警示。普通文件检查期间和检查后显示文件名，不闪现绝对路径；文件名入口定位文件夹，外部打开是单独的用户点击。PPT 默认点击进入现有 Otto 内部预览，失败不自动回退外部应用。

## 可复核性能数据

只测量控制指令字符数，不将字符当 token，不将脚本响应当真实模型成绩。运行：

```powershell
node scripts/measure-agent-output.mjs D:/otto/agent-baselines/stage5-20260908-001/source
```

脚本只读取新旧源码，在内存编译纯策略模块，对同一请求逐项断言非展示策略相等，不联网、调用模型或修改基线。

| 请求 | 阶段 5 字符 | 阶段 6 字符 | 差值 |
| --- | ---: | ---: | ---: |
| 你好 / 1 + 1 / 一句话解释向量数据库 | 1934 | 1412 | -522（约 27%） |
| 修复登录代码并运行测试 | 2020 | 2028 | +8 |
| 创建 PPT | 2021 | 2027 | +6 |
| 简短比较最新政策 | 2010 | 2029 | +19 |
| 部署服务器，只要结论 | 2034 | 2041 | +7 |

普通回答另外省去整段任务合同说明；工具 Schema、基础系统提示和历史上下文不包含在上述统计中。三个脚本提供者普通问答均只请求一轮；这证明本地编排没有额外审查轮，不证明真实模型必然一次回答正确。复杂任务指令基本持平，并未宣称所有任务的提示都变短。

## 明确边界

展示详略目前仍是保守文本提示识别，不是独立语义评审；为避免误删，无法判断价值的进展宁可保留。未完成内容仍保留必要的未验收提醒。普通文件当前提供安全定位/显式外部打开，不冒充任意格式均能应用内渲染；PPT 的渲染保真度沿用已有能力和限制。

未进行真实模型前后盲测、GUI 真人体验测试或真实费用/延迟比较；一次完成率、用户纠错次数及竞品差距留待阶段 7 固定模型实测。离线通过不等于整个脏工作区达到生产发布条件。
