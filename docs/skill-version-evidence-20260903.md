# 自动 Skill：功能说明、版本证据与用户回滚

## 本版交付边界

这是一版可运行的功能说明、版本证据和回滚基础设施，不是“任意 Skill 自动迭代到生产级”的实现。不得把静态校验通过、历史工作成功或模型自评分解释为业务可靠性保证。

入口沿用右侧“自动 Skill”。弹窗展示待确认功能与已安装个人 Skill 的版本记录；不改变企业模块的调用入口，也不操作官方内置 Skill。

## 用户能看到什么

- 中文功能名称与用途：帮用户完成什么、需要提供什么、交付什么、设计适用场景及不负责的事项。新生成提示词、离线模板、专家简介和对话候选摘要使用同一口径。旧内容没有说明的字段明确显示“尚未说明”，不补造能力。
- 三类信息分开：功能设计目标、代码的静态检查、实际案例的人工作业复核。没有业务样例时显示“尚未验证业务效果”，不是“检查通过，所以可以放心使用”。
- 版本比较：真实新增、修改、移除的文件；同一场景、输入、验收标准、模型与环境下的达标变化。没有相同条件的样例不作优劣结论。
- 实际试用记录：由用户在真实使用后填入脱敏输入、验收标准、实际输出、环境和通过/失败结论，并明确确认亲自复核。记录绑定整版文件与权限的 SHA-256 校验值；不接受模型分数冒充自动评测。
- 保留每次复核。对同版本同案例，只要存在失败就不能被后一次通过覆盖为稳定通过。界面列出失败和退步，不用总分平均掩盖问题。每版上限 200 次，满后拒绝写入，不静默覆盖旧证据。

## 版本与回滚

1. 主动要求修改同名个人 Skill 时进入增强草稿，而非直接覆盖。生成草稿时绑定当时已安装版本。
2. 用户确认更新前重新核对草稿与安装基线；期间人工修改文件则拒绝覆盖，要求重新查看与确认。
3. 更新前在个人用户目录的 `skill-versions/<skill-name>/<hash>/files/<skill-name>/` 保存完整快照，包括 SKILL.md、脚本、模板、参考材料与专家配置。原有单份 Markdown 历史不能作为完整恢复点。
4. 用户选择旧版后先看到将恢复、移除的文件及功能范围，勾选确认再回滚。回滚前再次核对当前版本、历史快照和现行静态校验。
5. 回滚整棵 Skill 文件树，移除新版独有文件；回滚前也保存当前版本，因此可再切回来。不撤销业务工单、发送的消息或已交付的文件。
6. 当前任务执行中禁止安装/更新/回滚；切换期间拒绝新消息接管。已有对话上下文不会重写，回滚后在新会话中使用。

本版不会在安装或回滚时运行草稿脚本。首次真实执行继续遵循原有依赖、权限、工具确认和业务提交机制。

## 安全和故障处理

- 仅合法个人 Skill 名称；拒绝内置名称、内置管理标记、目录越界、符号链接/Windows junction。
- 同一 Skill 的安装、回滚和复核写入互斥；保存快照后再替换，替换失败恢复当前目录。异常退出残留的锁不会自动抢占，需检查无运行操作后人工清理。
- 历史文件重新计算校验值，损坏历史显示警告并禁止用于回滚。活动文件一旦变化，旧版复核不会被展示为新版证据。
- 断线只允许短暂缓存只读版本查询，不缓存/重放回滚和复核写入。超时显示“未确认结果”，要求先刷新核对，而非自动重试写入。
- 不调用模型来生成分数或展示卡片；查看版本、记录复核、比较和回滚不增加模型 Token 消耗。正常生成 Skill 的既有模型调用不在此免耗范围。

## 验收方式

本次增加的覆盖包括：完整恢复/再次恢复能力、旧版脚本移除、模板和 profile 恢复、历史篡改、过期确认、并行互斥、目录链接、未确认写入拒绝、模型/环境不同不比较、失败记录不覆盖、真实 HTTP+WebSocket 版本查询与回滚、任务运行中拒绝切换、离线写入不重放、UI 勾选确认与错误状态。

可复现入口：

- Core：`src/orchestration/skillReleaseEvidence.test.ts`、`skillDraftWorkflow.test.ts`、`autoSkillGenerator.test.ts`、`src/tools/create-skill-draft.test.ts`。
- Server：`src/protocol.skill-releases.test.ts` 与 `src/server.test.ts` 的 Skill 真实 WS 用例。
- Desktop：`SkillVersionPanel.test.tsx`、`WorkspaceDialogs.test.tsx`、`useProductWorkspace.test.ts`、`workspaceCapabilityConversationBridge.test.ts`、`outbound-frame-queue.test.ts`。
- 可视化夹具：`packages/desktop/preview/skill-versions.tsx`。只含虚构数据，不连接正式账号或模型；用于浏览器查看真实组件和确认交互，不能冒充 Electron 完整端到端实测。

本地验证结果：Core 35 项、Server 124 项、Desktop 115 项，共 274 项通过。Core、Server、Desktop main/preload/renderer TypeScript 检查通过；全仓发布范围 ESLint、本次 Core 文件 ESLint、生产 renderer 构建、doctor、code-map 一致性与 diff 空白检查通过。浏览器已核对实际功能卡排版和勾选后的回滚确认；未运行用户真实业务 Skill，也未调用付费模型。

## 仍未实现，不能对外宣称已有

- 独立固定数据集上的全自动行为评测、重复试验、隐藏测试集、模型评审校准。
- 自动记录真实运行的成本/延迟/业务结果，再基于门槛自动晋级和有限轮迭代。
- 任意脚本自动沙箱执行、跨操作系统依赖矩阵、生产灰度与服务等级保证。

当前的业务比较证据来自用户实际试用后的人工复核，不是 Otto 独立验证过的生产认证。下一阶段接入自动运行器时，应追加明确的证据来源类型，绑定版本、固定案例、环境和原始产物；不得把现在的人工复核重命名为机器验证。
