# 阶段 5 补强：精确引文、口径绑定与弱测试审查

本轮只修改本地代码，没有推送、部署、重启客户端、修改生产数据或调用付费模型。延续既有 `ClaimEvidenceLedger → AgentTurnTracker → runtime` 和 `inspectTestSemantics → TaskContractLedger`，没有新增模型循环、路由状态 UI 或依赖。

## 本轮已实现

| 缺口 | 改动 | 正向与反向验收 |
| --- | --- | --- |
| 引用与正文脱节 | 引文必须链接真正包含该引文的来源；中性引用标签可直接使用，其他可见链接文字必须出现在对应证据中 | 正确引文可交付；附上另一来源链接、在链接标题中塞入虚构数字不能交付 |
| 证据接收失败后沿用旧通过结果 | 哈希/URL/时间/容量等校验失败立即使旧审查失效；失败状态不能靠重新提交旧正文或读取无关来源消除；同一调用的纠正回执可恢复；替换回执同时移除旧页 | 验证通过→坏回执→重新审查仍不通过→纠正原回执→重新审查通过；超限不能沿用旧结果 |
| 数字仅检查“出现过” | 数值推断必须有主体、指标、期间、单位、带符号值，绑定同一条无歧义原文；数值依据保留原文口径，再作自然语言推断 | 负数/小数/百分数可正常引用；换符号、把 billion 改成 million、跨句拼接主体和值、同段多指标无法区分均不能放行 |
| 只发现完全相同句型的冲突 | 有结构化口径时比较所有已读取来源的同口径单值段落，不要求语序一致；保存冲突原文、偏移、数值、URL、哈希和读取时间 | 漏掉不利来源仍能发现 42/45 冲突；不同年份、不同指标不混为一项；冲突说明要链接双方证据；明确不确定后可交付 |
| 多年份比较被误拦 | 请求期间按全部已登记结论合并覆盖，不再要求每一段同时包含所有年份；可以明确说明某年无证据 | 2025、2026 分段引用可通过；漏掉 2026 不通过；明确说明其数据不足可通过 |
| 测试有断言名称就算有效 | 检查断言和测试注册函数的词法绑定、来源及赋值；只识别已知匹配器，并确认匹配器确实连在该 `expect` 上 | 本地伪造/替换 expect、assert、test，假 toX、假链条、短路和 throw 后不可达断言均不计为验收 |
| 收紧后误拦正常测试 | 保留 Vitest 常规全局/ESM 导入及 Node ESM/CommonJS 原生断言路径；被替换的 require 不视为原生导入 | 正常异常断言、异步返回、解构值断言和 CommonJS 通过；另一测试的同名局部变量不干扰当前用例 |

输入和输出仍绑定当前请求、正文和来源版本。冲突明细每条结论最多 16 个、整轮最多 64 个；超过上限明确保留未通过，不能通过截断隐藏冲突。来源段落每次审查只切分一次，普通回答不进入这套流程。

## 仍未完成的语义能力

阶段 5 **不能标为 100% 完成**。本轮完成的是可执行的证据与弱测试检查补强，并非语义裁判：

1. 任意改写、翻译、算术、跨段因果推理尚无独立语义验证；数值推断暂要求保留原文依据，不把“可能”当数字免检通行证。其他自然语言的不确定性说明仍不能保证每个隐含断言都正确。
2. 口径字段仍由模型提出；不同措辞、不同单位和复杂表格的语义对齐并非全部可自动识别。矛盾检测是有限的段落/字面检查，不是通用自然语言矛盾识别。原始发布日期、官方发布者身份与真正最新来源尚无通用认证。
3. JS/TS 审查是弱测试下限，不能证明每个业务需求都测到了。复杂控制流、动态注册、辅助函数、自定义匹配器、跨文件猴子补丁及加载器行为仍需独立执行证据/人工审查；未知模式保留未验证，不自动取消验收。
4. 尚未独立审查全部隐含需求，也未统一接入 PDF、私有企业知识、GUI 观察的语义证据。
5. 固定真实模型 24 次对照仍未运行，未得到一次完成率、错误交付率、费用或耗时改善证据。不得据此发布或宣称达到其他 Agent 水平。
