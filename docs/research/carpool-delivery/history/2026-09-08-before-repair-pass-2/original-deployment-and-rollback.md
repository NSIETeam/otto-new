## 本地验证与迁移

- 使用 Node >=22.16、现有锁文件与依赖；没有修改无关依赖版本。
- SQLite contributor 自动为旧意向表增加 version，并创建 publications 表；必须先备份并在部署所用 SQLCipher 运行时验证。当前实测数据库是 Node SQLite + 字段加密，不等于 SQLCipher 真机验证。
- PostgreSQL 复用现有迁移及业务记录。实测临时 PostgreSQL 17 初始化全部现有迁移成功；本机 PostgreSQL 14 在现有迁移语法处失败，不应把 14 当已验证目标。
- 请求幂等记录包含位置副本，必须增加统一保留/删除任务后再通过隐私上线门禁。
- 配置沿用 OTTO_AMAP_WEB_SERVICE_KEY、OTTO_PARK_CARPOOL_MINIMUM_OVERLAP。没有读取真实密钥或启用新生产能力。
- 本地 PostgreSQL 契约：OTTO_CARPOOL_POSTGRES_TEST=1；可用 OTTO_CARPOOL_POSTGRES_BIN 指定已安装 PostgreSQL 17 bin。测试只创建独立临时目录和 Unix socket，无 TCP 监听；退出后停止并删除该测试目录。
