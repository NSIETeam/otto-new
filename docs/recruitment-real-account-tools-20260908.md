# 招聘下一步：真实账号样本验收入口与离线预检

日期：2026-09-08。接续自动正式入档。本轮交付的是验收工具与安全边界，**未完成真实 Workable 登录、真实模型分析或 PostgreSQL 多实例验收**，不改生产开关、不联系候选人。

## 本轮新增

### 1. 不用伪造生产验收标志即可验证一份样本

入口：“智能招聘 → 候选人来源 → Workable → 刷新本人授权”。

- 管理员先在验收服务器进程配置 `OTTO_WORKABLE_ACCEPTANCE_SCOPES`，精确限定企业 ID、本人账号 ID、共享岗位 ID、审批引用和到期时间。到期时间必须在当前时间之后且不超过七天，不支持通配符，不与生产批准标志混用。
- 本人仍须完成官方 OAuth 并绑定已发布的测试岗位。页面只在匹配限期许可时显示“读取一份测试简历（不调用模型）”。
- 勾选独立的样本读取确认后，最多查询当前绑定岗位的一位候选人，再尝试读取其简历，不继续翻页。确认普通账号连接检查不会自动同意样本读取。
- 测试岗位应只放已获准使用的合成或去标识化样本。当前不提供从大规模生产岗位中挑选样本的列表，因此不能用生产人才库随意试读。
- 严格沿用既有官方只读工具、本人令牌、岗位绑定、附件 origin 审核、DNS/下载限制与提取器。没有审批附件 origin 时通常只能取得部分结构化资料，界面不会显示全文验收通过。
- 保存到本人加密授权记录的仅为时间、编号、正文/来源指纹、完整度、字符数及可用的附件摘要。没有保存简历正文、姓名、签名下载地址或模型输出；已有授权凭据仍由原加密仓库管理。
- 刷新后可以回查最近一份当前绑定适用的报告；重新绑定、重新授权或撤销后，旧报告不再冒充当前连接的验证结果。不是多轮完整验收报告库。
- 状态分别为“全文读取成功”“部分资料”“无正文”“空岗位”。空岗位不等于简历读取通过；全文读取成功也不代表判断准确、模型可用、共享闭环或生产验收通过。
- 不修改 `OTTO_WORKABLE_REAL_ACCOUNT_VERIFIED`，不启用后台接收/付费分析/自动入档，不创建正式候选人、不发消息。无自动重试；关闭桌面只会丢弃迟到界面响应，不能承诺撤回已发出的服务端只读请求。撤权/变更许可与绑定会在后续读写检查中阻止继续采用旧结果。

运维示例（非密钥，仅用于说明结构，**本轮没有设置**；替换全部 ID、审批引用和到期时间）：

```json
[
  {
    "organizationId": "test-enterprise-id",
    "actorAccountId": "test-hr-id",
    "jobId": "test-job-id",
    "expiresAt": "2026-09-09T12:00:00Z",
    "approvalReference": "approved-isolated-test-record"
  }
]
```

新增客户端/服务器能力标记 `recruitment_workable_acceptance_v1`。旧服务器不会收到样本读取请求。SQLite 和 PostgreSQL 宿主共用原 Workable 授权服务与加密存储；新增字段要求读写实例升级，不能未经兼容性验证混用旧服务器。

### 2. 离线配置预检

在仓库根目录构建 server 后执行：

```powershell
npm run recruitment:check --workspace=otto-server -- --org <企业ID> --actor <账号ID> --job <共享岗位ID>
```

检查当前进程里的 OAuth 入口、限期样本许可、附件域名配置、所选企业模型路由以及 PostgreSQL 连接串语法。输出 `configured / missing / invalid` 与固定说明，不回显秘密或连接串。

此命令不读取 `.env` 或远程部署配置，不打开数据库、不读取 OAuth 仓库、不发网络请求、不调用模型、不迁移数据、不启用生产。若在开发机运行，其结果不能代替远端服务器配置状态。全部配置存在仅退出 0；缺失/不匹配退出 2。无论退出码如何，`liveAcceptance` 都是 `not_run`。

## 真实验收还需要什么

1. 本人可授权的真实 Workable 企业账号和已发布测试岗位；登录经官方浏览器，不在聊天中发送密码、验证码或令牌。
2. 获准读取、分析、保存和共享的测试材料，以及已经批准的模型与小额测试预算。
3. 隔离验收服务器及实际 PostgreSQL，之后再运行“两位 HR、两个服务器实例、断网、撤权、重启”的验收。Docker 可执行文件存在不代表守护进程可用；本机只读 `docker info` 因权限被拒绝，本轮未启动容器或连接数据库。

本次本地测试使用合成材料和模拟官方响应，覆盖默认禁止、独立确认、跨账号/岗位、到期、超量拒绝、部分资料、撤权、报告保密与绑定失效、旧客户端能力、离线无网络。不是招聘质量评测或真实平台验收。

本轮验证：服务端招聘 271 项、桌面招聘 178 项、集群宿主 41 项、定向 HTTP 权限 1 项，共 491 项测试通过；服务端与桌面类型检查、服务端构建、桌面渲染构建、改动文件 ESLint、doctor、代码地图检查和 `git diff --check` 通过。本轮没有提交、推送或部署。

完整人工验收顺序见 [真实账号联调清单](recruitment-real-account-checklist-20260908.md)。先使用新增入口取得实际只读样本证据，再由部署负责人决定后续受控分析、共享与生产批准；不把页面按钮变多作为接通平台的证明。
